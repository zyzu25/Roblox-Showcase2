---
name: Loading screen branding
description: Branding boundary between the portfolio splash screen and selectable site themes
---

The loading screen should retain the MYSTICFUSION7X signature as its brand mark. Site theme changes, including the Novara-inspired purple palette, must not replace the signature with a community or client logo.

**Why:** The signature identifies the portfolio creator, while selectable themes are visual treatments for the portfolio experience.

**How to apply:** Treat loading-screen logo/content changes and site theme palette changes as separate concerns; only change the splash branding when explicitly requested.
